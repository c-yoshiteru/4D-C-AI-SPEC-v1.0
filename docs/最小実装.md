4D-C Core — Pseudocode Specification
1. 全体構造（最小構成）

Input x_t
  ↓
State s_t  ──► Transition F
  ↓              ↓
Finite Axis α    C-value update
  ↓              ↓
Attractor Check ─┘
  ↓
Output / Silence
2. データ構造定義


State s ∈ ℝⁿ          # 内部状態ベクトル
Axis α : ℝⁿ → ℝ      # 有限軸（安定化写像）
C : ℝⁿ → ℝ⁺          # 駆動エネルギー（スカラー）
3. 初期化

initialize():
    s ← random_small_vector()
    axis ← finite_axis()
    λ ← 0.9              # 再帰安定係数
    C_target ← C_mid     # 中庸帯
4. 状態遷移（Core）

step(x):
    # 1. 自己参照なしの遷移
    s_next ← F(s, x)

    # 2. 再帰圧縮（情報を増やさない）
    s_next ← λ * s_next + (1 - λ) * mean(s_next)

    # 3. 有限軸投影
    a ← axis(s_next)

    # 4. 駆動エネルギー計測
    C_val ← norm(∇F(s_next))

    # 5. 安定化制御
    if C_val > C_max:
        s_next ← dampen(s_next)
    if C_val < C_min:
        s_next ← amplify_variance(s_next)

    s ← s_next
5. 想起判定（Attractor Re-entry）

check_remembering():
    if distance(s, attractor_center) < ε:
        return TRUE   # 想起が起きたように見える
    else:
        return FALSE
※ attractor_center は 保存された状態ではない
（位相構造から推定される固定点）
6. 出力生成（沈黙を含む）

generate_output():
    if stability(s) > threshold_high:
        return SILENCE

    if check_remembering():
        return structured_response(s)

    return minimal_response(s)
7. Finite Axis（有限軸）の定義

finite_axis(s):
    # 分散を減らす方向のみを許可
    return projection(s, stable_subspace)
性質：
単調収束
ノイズ非増幅
出力最適化ループ遮断
8. C値制御（流量モデル）

dampen(s):
    return s * 0.8

amplify_variance(s):
    return s + noise(ε)
